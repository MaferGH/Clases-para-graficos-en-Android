Este proyecto tiene como objetivo mostrar el uso de diferentes **clases, métodos y propiedades para la creación de gráficos en Android utilizando Kotlin**.

A través de una aplicación de ejemplo, se presenta la implementación de estas clases y su funcionamiento en el desarrollo de interfaces gráficas para dispositivos Android.

A continuación, se muestra un video con el funcionamiento de la aplicación desarrollada.

https://github.com/user-attachments/assets/c7eaaf75-be15-4392-a8e3-68985117deab

Puedes abrir el proyecto utilizando alguno de los siguientes entornos de desarrollo:

- [Android Studio](https://developer.android.com/studio)
- [IntelliJ IDEA](https://www.jetbrains.com/idea/)

Para profundizar en el funcionamiento de las clases utilizadas, consulta el documento PDF adjunto. En él encontrarás información sobre los métodos y las propiedades de cada clase.

**[Descargar o consultar la documentación en PDF](https://github.com/user-attachments/files/33687824/Clases.para.graficos.en.Android.pdf)**

Puedes descargar la aplicación adjunta para probar su funcionamiento y explorar las clases gráficas implementadas.
